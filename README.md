# rs-485
Модуль управления нагрузкой на МК с интерфейсом rs-485
Модуль управления на STM32F103C8T6 и с изолированным трансивером ADM2587EBRWZ-REEL7
Применена двухступенчатая система питания на импульсном dc-dc LM2596S-5.0 и линейном стабилизаторе AMS1117-3.3
Цифровая и силовая земля разделены
Нагрузка до 2А
